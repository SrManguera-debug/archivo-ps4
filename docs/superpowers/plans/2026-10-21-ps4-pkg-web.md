# PS4 Package Library — Implementation Plan

Date: 2026-10-21
Design: `docs/superpowers/specs/2026-10-21-ps4-pkg-web-design.md`

## Goal

Ship a working self-hosted app at `http://192.168.1.20:8081` that authenticates,
browses the real PKG library, extracts icons/SFO metadata, manages multiple PS4s,
queues installs through RPI with pause/resume, and extracts RARs with progress.

## Constraints

- Python 3.11+ stdlib only for the app (no pip packages at runtime).
- Vanilla HTML/CSS/JS frontend, no build step.
- All package data stays under `/mnt/juegos_ps4/descargas`; all app writes under
  `/var/lib/ps4web` and `/etc/ps4web`.
- Tests use `unittest` and a fake RPI server. No network required except the
  on-server smoke test.
- Commit after every task.

## Task 1 — Scaffold, config, auth primitives

**Files:** `ps4web/__init__.py`, `ps4web/config.py`, `ps4web/auth.py`,
`tests/test_config.py`, `tests/test_auth.py`, `README.md`, `.gitignore`.

**Interfaces:**
- `Config` dataclass with `library_root`, `public_base_url`, `listen_host`,
  `listen_port`, `subnet`, `state_dir`, `cache_dir`, `auth_user`,
  `auth_password_hash`, `session_secret`, `rpi_pkg`, `scan_ports`, `app_version`.
- `load_config(path: str | None = None) -> Config`; env `PS4WEB_CONFIG` selects
  the path, defaults to `/etc/ps4web/config.json`; refuses a missing file with a
  clear error.
- `init_config(path, library_root, public_base_url, ...) -> tuple[Config, str]`
  returns config plus generated plaintext password.
- `hash_password(password, salt=None) -> str` in format
  `pbkdf2_sha256$200000$<salt_hex>$<hash_hex>`.
- `verify_password(password, stored) -> bool` with `hmac.compare_digest`.

**Tests:** round-trip hash/verify, wrong password, salt uniqueness, config
round-trip and mode 600, missing file error.

## Task 2 — PKG/SFO/icon parsing

**Files:** `ps4web/pkg.py`, `tests/test_pkg.py`, `tests/pkg_fixture.py`.

**Interfaces:**
- `PkgInfo` dataclass (title, title_id, content_id, version, app_ver, category,
  system_ver, firmware, size, mtime, path).
- `parse_pkg(path: Path) -> PkgInfo`; raises `PkgError` with a useful message.
- `extract_icon(path: Path) -> bytes | None`; validates PNG magic; tries entry
  `0x1200` then `0x1220`.
- `format_firmware(system_ver: int) -> str` BCD: `0x10008000` → `10.00.80`.
- `package_kind(info) -> "base" | "patch" | "dlc" | "other"`.
- `sort_packages(infos) -> list[PkgInfo]` base, patch, DLC, other; stable by
  title id then filename.
- `version_tuple(text) -> tuple[int, ...]` for compatibility warnings.

**Implementation notes:** big-endian header at 0x00; entry table at table offset,
0x20 bytes per entry; SFO entry 0x1000; parse SFO little-endian. Entry offsets
are absolute; fall back to `body_offset + offset` only if the magic check fails.
Cap SFO read at 1 MiB.

**Tests:** synthetic PKG fixture with SFO + PNG; real `/tmp/opencode/rpi.pkg` if
present; invalid magic; truncated table; firmware cases; sorting; icon absent.

## Task 3 — Library browser

**Files:** `ps4web/library.py`, `tests/test_library.py`.

**Interfaces:**
- `Library(root: Path, cache_dir: Path)`.
- `resolve(rel: str) -> Path`: reject absolute paths, `..`, NUL, symlinks that
  escape; `""` means root.
- `listing(rel: str) -> dict` with `path`, `parent`, `breadcrumb`, `entries`,
  `disk`, `root`.
  - Entry: `name`, `path`, `type` (`dir`/`pkg`/`rar`/`file`), `size`, `mtime`,
    plus PKG fields and `icon_url` for PKGs.
- `find_packages(rel: str) -> list[PkgInfo]` recursive.
- `all_packages_under(rel)` respects `include_dlc`.
- Caches PKG info by `(path, mtime, size)` and icons by SHA-1; invalidate on
  directory mtime changes. Thread-safe with a lock.
- `disk_stats()`.

**Tests:** traversal attempts, listing root/nested, hidden files skipped, RAR
recognition, cache hit returns same object, recursive scan sorted.

## Task 4 — Console registry, probe, discovery, FTP

**Files:** `ps4web/consoles.py`, `tests/test_consoles.py`.

**Interfaces:**
- `Console` dataclass; `ConsoleStore(state_dir)` with `list()`, `get(id)`,
  `add(name, ip, rpi_port=12800, ftp_port=2121, firmware="", notes="")`,
  `update(id, **fields)`, `delete(id)`, atomic JSON persistence.
- `validate_ip(ip)`, `validate_port(port)`.
- `probe(console, timeout=0.4) -> dict` checks 12800/12801 (RPI), 2121 (FTP),
  9295 (Remote Play); returns booleans + `online`.
- `discover(subnet: str, ports=(12800,12801,2121,9295), timeout=0.25)` thread
  pool, max 256 hosts, excludes own IP; returns `[{ip, ports}]`.
- `prepare_rpi(console, rpi_pkg, ftp_port) -> str` uploads via `ftplib` to
  `/data/pkg/<name>`; anonymous login; raises `ConsoleError`.

**Tests:** CRUD persistence, invalid IP/port, probe with local listener, discover
finds local listener, FTP upload against `pyftpdlib` if available else mock.

## Task 5 — RPI client and lenient JSON

**Files:** `ps4web/rpi.py`, `tests/test_rpi.py`, `tests/fake_rpi.py`.

**Interfaces:**
- `RpiClient(ip, port=12800, timeout=15)` with `install(urls)`,
  `progress(task_id)`, `pause(task_id)`, `resume(task_id)`, `stop(task_id)`,
  `is_exists(title_id)`.
- `parse_lenient_json(text) -> dict`: rewrite unquoted `0x...` literals to
  decimal; raise `RpiError` on truly invalid JSON.
- `progress_snapshot(resp) -> dict` normalizes:
  `percent`, `phase`, `transferred`, `total`, `eta`, `done`, `error`, `raw`.
- `RpiError` carries `status`, `body`, `url`.

**Tests:** fake RPI install/progress/pause/resume; hex JSON parse; progress math
for download/install/done/error; HTTP failure.

## Task 6 — Persistent jobs and workers

**Files:** `ps4web/jobs.py`, `tests/test_jobs.py`.

**Interfaces:**
- `Job` dataclass and `JobStore(state_dir)` atomic persistence, pruning to 200.
- `JobManager(config, console_store, library)` with `create_install_batch`,
  `create_extract`, `list(console_id=None)`, `get`, `pause`, `resume`, `cancel`,
  `retry`, `shutdown`.
- One worker thread per console; one extraction worker. Install worker:
  validate package, build nginx URL, call RPI install, poll every 2 s, update
  progress, handle pause/resume, mark done/error. Retry on transient connection
  error up to 3 times with backoff for the initial RPI call.
- Batch ordering base → patch → DLC; skip duplicates already queued/running for
  that console; skip DLC when `include_dlc=False`.
- Extraction worker: `7z l -slt` for size + path validation, disk guard, then
  `7z x -y -bsp1 -o<parent> <archive>` parsing `NN%`; `cancel` terminates.
- Startup: interrupted active jobs → `error`.

**Tests:** enqueue order, duplicate skip, fake install progress to done,
pause/resume calls recorded, cancel, extraction with a stub 7z script,
disk guard, restart marking.

**Tests:** start on ephemeral port; login/logout; unauthenticated 401; CSRF

RPI; pause; stats; static login page.
